# Diti Screenshots & Visual Assets

This directory stores visual assets and screenshots used in the root [README.md](../../README.md) and documentation.

## Suggested Screenshots

To showcase Diti's core features to prospective users, we welcome high-quality PNG screenshots (preferably in dark and light modes, captured at native resolution):

1. **`routine-timer.png`**: The active multi-phase timer screen showing current phase, countdown ring, and phase controls.
2. **`daily-planner.png`**: Today's time-blocked plan showing planned blocks and scheduled routines.
3. **`activity-breakdown.png`**: The analytics and session breakdown view displaying time distribution across activities.
4. **`routine-builder.png`**: The routine configuration screen showing multi-phase reordering and duration settings.

## Contribution Guidelines

- Format: PNG
- Recommended Android resolution: 1080x2400 (or standard phone aspect ratios)
- Recommended Linux desktop resolution: 1280x800 or window crop
- After adding screenshots, update the visual showcase in the root [README.md](../../README.md).
